# Correspondances entre pseudo-code GNS et Java

| GNS pseudo-code | Java equivalent | Explication |
| --- | --- | --- |
| `pour j ← 0 à taille1 − 1` | `for (int j = 0; j < taille1; j++) { … }` | Le GNS emploie un bloc **POUR** pour parcourir une série de valeurs, ce qui correspond à la syntaxe `for` où l’on fixe l’initialisation, la condition et la mise à jour dans l’en-tête de la boucle Java.【F:year_1/319/resources/excerpts/presentationgns_excerpt.md†L1-L4】【F:year_1/319/resources/excerpts/java_manual_control_structures.md†L5-L5】 |
| `tant que condition` | `while (condition) { … }` | Les diagrammes GNS prévoient des répétitions, et le cours précise que les boucles indéfinies `while` servent quand on répète tant qu’une condition reste vraie; la syntaxe Java place cette condition en tête du `while`.【F:year_1/319/resources/excerpts/presentationgns_excerpt.md†L1-L3】【F:year_1/319/resources/excerpts/cours_structures_boucles_excerpt.md†L4-L5】【F:year_1/319/resources/excerpts/java_manual_control_structures.md†L3-L3】 |
| `faire bloc tant que condition` | `do { bloc; } while (condition);` | Pour un bloc à exécuter au moins une fois en GNS, on utilise un schéma de répétition vérifiée en sortie, que le cours relie aux boucles `do while`; la forme Java teste la condition après le bloc, ce qui garantit un passage initial.【F:year_1/319/resources/excerpts/cours_structures_boucles_excerpt.md†L4-L5】【F:year_1/319/resources/excerpts/java_manual_control_structures.md†L4-L4】 |
| `si condition alors bloc1 sinon bloc2` | `if (condition) { bloc1; } else { bloc2; }` | Les structures de choix GNS couvrent des tests logiques, et le manuel montre la syntaxe `if`/`else` qui exécute un bloc quand la condition est vraie puis une alternative sinon, exactement comme un bloc **SI/SINON** du diagramme.【F:year_1/319/resources/excerpts/cours_structures_choix_excerpt.md†L3-L4】【F:year_1/319/resources/excerpts/java_manual_control_structures.md†L6-L6】 |
| `selon expression : cas …` | `switch (expression) { case … break; … }` | Pour sélectionner un chemin parmi plusieurs cas en GNS, on peut employer une structure **switch** ; le manuel détaille la syntaxe Java avec `case` et `default`, qui correspond aux branches d’un bloc **SELON**.【F:year_1/319/resources/excerpts/cours_structures_choix_excerpt.md†L3-L3】【F:year_1/319/resources/excerpts/java_manual_control_structures.md†L7-L7】 |
